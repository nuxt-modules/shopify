This guide will walk you through the installation and initial configuration of the Nuxt Shopify module.

::note
Click [here](/essentials/setup-shopify) if you need help setting up Shopify.
You can start building without a store using [mock.shop](https://mock.shop) but you won't have access to real data.
If you are upgrading from version 1, follow the [migration guide](/going-further/migration).
::

## Installation

::steps{level="4"}

  #### Add the module to your app

  ::tabs{.w-full}
    :::tabs-item{label="Guided"}
      :::code-group
        ```bash [npm]
        npx nuxi@latest module add shopify
        ```

        ```bash [pnpm]
        pnpm dlx nuxi@latest module add shopify
        ```

        ```bash [bun]
        bunx nuxi@latest module add shopify
        ```
      :::
    :::

    :::tabs-item{label="Manual"}
      :::code-group
        ```bash [npm]
        npm install @nuxtjs/shopify @shopify/hydrogen
        ```

        ```bash [pnpm]
        pnpm add @nuxtjs/shopify @shopify/hydrogen
        ```

        ```bash [bun]
        bun add @nuxtjs/shopify @shopify/hydrogen
        ```
      :::

      And then add the module to your Nuxt config:

      ```ts [nuxt.config.ts]
      export default defineNuxtConfig({
        modules: ['@nuxtjs/shopify'],
      })
      ```
    :::
  ::

  ::note
  The module requires Nuxt 4 or newer and `@shopify/hydrogen` 2026.10.3 or newer.
  Hydrogen is a peer dependency of the module, so you need to install it as well, as shown above.
  The guided install adds it for you.
  ::

  #### Configure the module

  :::tabs
    ::::tabs-item{label="Storefront API"}
    ```ts [nuxt.config.ts]
    export default defineNuxtConfig({
      shopify: {
        name: 'nuxt-module-store',

        clients: {
          storefront: {
            apiVersion: '2026-10',
            publicAccessToken: '...',
            privateAccessToken: '...',
          },
        },
      }
    })
    ```
    ::::

    ::::tabs-item{label="Storefront API (Mock)"}
    ```ts [nuxt.config.ts]
    export default defineNuxtConfig({
      shopify: {
        name: 'my-mocked-store',

        clients: {
          storefront: {
            apiVersion: '2026-10',
            mock: true,
          },
        },
      }
    })
    ```
    ::::

    ::::tabs-item{label="Customer Account API"}
    ```ts [nuxt.config.ts]
    export default defineNuxtConfig({
      shopify: {
        name: 'nuxt-module-store',

        defaultMarket: {
          country: 'US',
          language: 'EN',
        },

        clients: {
          customerAccount: {
            apiVersion: '2026-10',
            clientId: '...',
          },
        },
      }
    })
    ```

    Without the storefront client, the module can't fetch your shop's default market, so you need to set `defaultMarket`.
    Customers can only log in on an HTTPS domain other than `localhost`.
    To log in during development, see [local development](/essentials/customer-account#local-development).
    ::::

    ::::tabs-item{label="Admin API"}
    ```ts [nuxt.config.ts]
    export default defineNuxtConfig({
      shopify: {
        name: 'nuxt-module-store',

        clients: {
          admin: {
            apiVersion: '2026-10',
            clientId: '...',
            clientSecret: '...',
          },
        },
      }
    })
    ```
    ::::
  :::
::

And that's it! You can now start using Nuxt Shopify.

The full module configuration reference can be found [here](/essentials/configuration).

For a quick setup you can also use the prebuilt Shopify example store template:

::code-group
  ```bash [npm]
  npx nuxi@latest init -t gh:nuxt-modules/shopify/template ./my-shop
  ```

  ```bash [pnpm]
  pnpm dlx nuxi@latest init -t gh:nuxt-modules/shopify/template ./my-shop
  ```

  ```bash [bun]
  bunx nuxi@latest init -t gh:nuxt-modules/shopify/template ./my-shop
  ```
::

This will set up a full example store into the `my-shop` directory.
