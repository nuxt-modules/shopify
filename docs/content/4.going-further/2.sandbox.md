The Nuxt Shopify module creates a sandbox for each API client that
you can access in development mode to explore and test your GraphQL queries.

When starting the Nuxt development server you can then access each sandbox in your browser:

* http://localhost:3000/_sandbox/storefront
* http://localhost:3000/_sandbox/customer-account
* http://localhost:3000/_sandbox/admin

::warning
Sandboxes are only registered in dev mode, and they are unauthenticated: anyone who can reach your dev server can run
queries against the configured clients, including the Admin API. Set `sandbox: false` on the admin client (or bind the
dev server to `localhost` only) when sharing your dev server over a tunnel or a local network.
::

By default, each client sets up a sandbox when running in dev mode.
You can customize this behavior by setting the `sandbox` option in the client config:

```ts [~/nuxt.config.ts]
export default defineNuxtConfig({
  shopify: {
    clients: {
      storefront: {
        sandbox: true,
      },
      customerAccount: {
        sandbox: false,
      },
      admin: {
        sandbox: true,
      },
    },
  },
})
```
