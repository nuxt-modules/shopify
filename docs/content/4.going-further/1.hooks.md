The module provides several hooks that can be used to customize its behavior. 
Build-time hooks are set in the `hooks` property of your `nuxt.config.ts`, and runtime hooks in Nuxt and Nitro plugins.

## Using client runtime hooks

You can use the client runtime hooks in a Nuxt plugin or Nitro plugin to customize the behavior of any client:

### Client-side hooks examples

::code-group
```ts [app/plugins/storefront.ts]
export default defineNuxtPlugin((app) => {
  app.hooks.hook('shopify:storefront:client:configure', ({ config }) => {
    // Modify the config of the client before it is created
    config.headers['X-Request-Source'] = 'nuxt-shopify'
  })

  app.hooks.hook('shopify:storefront:client:create', () => {
    console.log('Storefront client created')
  })

  app.hooks.hook('shopify:storefront:client:request', ({ operation, options }) => {
    console.log('Storefront client request sent:', operation, options)
  })

  app.hooks.hook('shopify:storefront:client:response', ({ response, operation, options }) => {
    console.log('Storefront client response received:', response, operation, options)
  })

  app.hooks.hook('shopify:storefront:client:errors', ({ errors }) => {
    console.log('Storefront client errors:', errors)
  })
})
```

```ts [app/plugins/customer-account.ts]
export default defineNuxtPlugin((app) => {
  app.hooks.hook('shopify:customer-account:client:configure', ({ config }) => {
    // Modify the config of the client before it is created

  })

  app.hooks.hook('shopify:customer-account:client:create', () => {
    console.log('Customer account client created')
  })

  app.hooks.hook('shopify:customer-account:client:request', ({ operation, options }) => {
    console.log('Customer account client request sent:', operation, options)
  })

  app.hooks.hook('shopify:customer-account:client:response', ({ response, operation, options }) => {
    console.log('Customer account client response received:', response, operation, options)
  })

  app.hooks.hook('shopify:customer-account:client:errors', ({ errors }) => {
    console.log('Customer account client errors:', errors)
  })
})
```
::

::note
The `configure` hooks run synchronously when the client is created, so change `config` before you `await` anything.
Custom headers that you set in the browser don't reach Shopify, because the [Storefront API proxy](/essentials/storefront#the-storefront-api-proxy) and the [customer account proxy](/essentials/customer-account#the-customer-account-proxy) don't forward them.
::

::warning
During server-side rendering, the `config` of the storefront client contains the `privateAccessToken` and the buyer's IP address, and the `config` of the customer account client contains the customer's access token.
Don't put `config` or the clients in `useState` or anything else that is sent to the browser.
Don't log them either, because `nuxt dev` also shows server logs in the browser console.
::

### Customer account auth hooks

The customer account authentication flow runs entirely on the server, so these hooks are only available in a Nitro plugin.
Use them to run code after a login or logout, or when a token is refreshed.
Each hook receives the request event, so you can load the customer with `useCustomerAccount(event)` in the `success` and `refresh` hooks.
The `logout` and `error` hooks run without a session, so you can't load the customer there.
The hooks don't receive the customer's tokens.

```ts [server/plugins/account.ts]
export default defineNitroPlugin((app) => {
  app.hooks.hook('shopify:customer-account:auth:success', async ({ event }) => {
    // React to a successful login (sync the customer to a CRM, track analytics, ...)
    const { data } = await useCustomerAccount(event).request(`#graphql
      query LoggedInCustomer {
        customer { emailAddress { emailAddress } }
      }
    `)

    console.log('Customer logged in:', data?.customer.emailAddress?.emailAddress)
  })

  app.hooks.hook('shopify:customer-account:auth:refresh', () => {
    console.log('Access token refreshed')
  })

  app.hooks.hook('shopify:customer-account:auth:logout', () => {
    console.log('Customer logged out')
  })

  app.hooks.hook('shopify:customer-account:auth:error', ({ event }) => {
    console.error('Customer account login failed:', event.path)
  })
})
```

To change the login options, such as the language of Shopify's login page, pass them to `login()` from [`useCustomerAccountSession`](/essentials/customer-account#the-session-composable).
The `error` hook doesn't receive the reason why a login failed.

### Admin auth hooks

The admin API authenticates with a machine-to-machine OAuth flow (client credentials, with refresh token rotation), so these hooks are only available in a Nitro plugin.
Use them to customize the token request, or to observe when an access token is issued, refreshed, or fails to issue.

These hooks only fire when the module obtains a token on your behalf. They are skipped when a static `accessToken` is configured.

```ts [server/plugins/admin-auth.ts]
export default defineNitroPlugin((app) => {
  app.hooks.hook('shopify:admin:auth:request', ({ params }) => {
    // Mutate the token request body before it is sent
    params.scope = 'my-custom-scope'
  })

  app.hooks.hook('shopify:admin:auth:success', ({ token }) => {
    // React to a freshly issued access token (client credentials grant)
    console.log('Admin access token obtained, expires at:', token.expiresAt)
  })

  app.hooks.hook('shopify:admin:auth:refresh', ({ token }) => {
    console.log('Admin access token refreshed, expires at:', token.expiresAt)
  })

  app.hooks.hook('shopify:admin:auth:error', ({ error }) => {
    console.error('Admin token request failed:', error)
  })
})
```

## Hooks reference

Hooks allows you to hook into the different stages of the module lifecycle.

### Nuxt Hooks (Build Time)

| Hook                                              | Arguments        | Environments | Description                                                                 |
| ------------------------------------------------- | :--------------: | :----------: | --------------------------------------------------------------------------- |
| `shopify:config`                                  | `nuxt`, `config` | Server       | Called before the parsed module config is persisted into the runtime config |
| `shopify:setup`                                   | `nuxt`, `config` | Server       | Called after the module setup is completed                                  |
| `shopify:storefront:generate:introspection`       | `nuxt`, `config` | Server       | Called before the storefront introspection schema is generated              |
| `shopify:storefront:generate:types`               | `nuxt`, `config` | Server       | Called before the storefront types are generated                            |
| `shopify:storefront:generate:operations`          | `nuxt`, `config` | Server       | Called before the storefront operations are generated                       |
| `shopify:customer-account:generate:introspection` | `nuxt`, `config` | Server       | Called before the customer account introspection schema is generated        |
| `shopify:customer-account:generate:types`         | `nuxt`, `config` | Server       | Called before the customer account types are generated                      |
| `shopify:customer-account:generate:operations`    | `nuxt`, `config` | Server       | Called before the customer account operations are generated                 |
| `shopify:admin:generate:introspection`            | `nuxt`, `config` | Server       | Called before the admin introspection schema is generated                   |
| `shopify:admin:generate:types`                    | `nuxt`, `config` | Server       | Called before the admin types are generated                                 |
| `shopify:admin:generate:operations`               | `nuxt`, `config` | Server       | Called before the admin operations are generated                            |

### App Hooks (Runtime)

| Hook                                        | Arguments                          | Environments    | Description                                                        |
| ------------------------------------------- | :--------------------------------: | :-------------: | ------------------------------------------------------------------ |
| `shopify:analytics:ready`                   | `shop`, `i18n`                     | Client          | Called once Shopify's scripts are running for the resolved shop    |
| `shopify:storefront:client:configure`       | `config`                           | Server & Client | Called before the storefront client is created                     |
| `shopify:storefront:client:create`          | `client`                           | Server & Client | Called after the storefront client is created                      |
| `shopify:storefront:client:request`         | `operation`, `options`             | Server & Client | Called before the storefront client sends a request                |
| `shopify:storefront:client:response`        | `response`, `operation`, `options` | Server & Client | Called after the storefront client receives a response             |
| `shopify:storefront:client:errors`          | `errors`                           | Server & Client | Called when a storefront client request contains errors            |
| `shopify:customer-account:client:configure` | `config`                           | Server & Client | Called before the customer account client is created               |
| `shopify:customer-account:client:create`    | `client`                           | Server & Client | Called after the customer account client is created                |

| `shopify:customer-account:client:errors`    | `errors`                           | Server & Client | Called when a customer account client request contains errors      |
